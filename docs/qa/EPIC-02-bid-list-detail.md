# EPIC-02 공고 목록/상세 화면 적합도 반영 시나리오

대상 화면: `/` (`BidListPage`, 적합도 배지/필터 추가분), `/bids/:bidId` (`BidDetailPage`, 신규)

---

## 시나리오 1: 골든 패스 — 목록에서 적합도 배지/필터 확인 후 상세 진입

- 사전조건: 로그인된 상태, 회사 프로필이 설정되어 있고 매칭 결과(`bid_match_results`)가 계산된 공고가 여러 등급(적극 검토/추천/검토 필요)으로 최소 1건씩 존재한다.
- 절차:
  1. `/` 접속
  2. 공고 카드마다 적합도 배지("등급 N점" 형태)가 D-Day 배지 옆에 표시되는지 확인
  3. `grade` 필터를 "적극 검토"로 선택
  4. `grade` 필터를 "전체"로 되돌린 뒤, 적합도 배지가 있는 공고 카드를 클릭
- 기대 결과:
  - 2번: 배지 색상이 80점↑ 초록 / 60~79점 주황 / 60점↓ 회색으로 표시된다
  - 3번: 목록이 "적극 검토" 등급 공고만으로 필터링된다
  - 4번: `/bids/{bidId}`로 이동하고, 공고 기본 정보/적합도 섹션(총점·등급·세부 점수·추천 사유)/일정/첨부파일/AI 요약·위험 요인·유사 공고(placeholder) 섹션이 순서대로 표시된다

## 시나리오 2: 회사 프로필 미설정 안내

- 사전조건: 로그인된 상태이나 해당 계정에 회사 프로필이 없음(`GET /api/companies/me` 응답 `data: null`)
- 절차:
  1. `/` 접속
- 기대 결과:
  - 검색바 아래에 "회사 프로필을 설정하면 적합도를 확인할 수 있습니다." 안내 배너와 "프로필 설정하기" 링크가 표시된다
  - 공고 카드의 적합도 배지는 모두 "미설정"(회색)으로 표시된다

## 시나리오 3: 상세 화면 Loading / Error / Not Found

- 사전조건: 로그인된 상태
- 절차:
  1. 존재하는 `bidId`로 `/bids/{bidId}` 접속 시 네트워크 지연을 걸어(또는 첫 로드 순간) 스켈레톤 UI 확인
  2. Playwright MCP로 `/api/bids/{bidId}` 응답을 5xx로 가로채 재현 → 에러 메시지 + "다시 시도" 버튼 확인 → 정상 응답으로 원복 후 "다시 시도" 클릭
  3. 존재하지 않는 `bidId`(예: `/bids/999999999`)로 접속
- 기대 결과:
  - 1번: 스켈레톤 UI가 잠시 보인 뒤 실제 데이터로 전환된다
  - 2번: 에러 메시지와 "다시 시도" 버튼이 표시되고, 원복 후 재시도하면 정상 데이터가 로드된다
  - 3번: "공고를 찾을 수 없습니다."와 "목록으로 돌아가기" 링크가 표시되고, 재시도 버튼은 없다 (2번의 일반 에러 상태와 구분됨)

## 시나리오 4: 첨부파일 다운로드 링크

- 사전조건: 로그인된 상태, 첨부파일이 1개 이상 있는 공고
- 절차:
  1. 해당 공고 상세 화면 접속
  2. 첨부파일 섹션에서 파일명 링크 클릭
- 기대 결과: 새 탭에서 나라장터 원본 다운로드 URL이 열린다 (우리 서버를 거치지 않음)
