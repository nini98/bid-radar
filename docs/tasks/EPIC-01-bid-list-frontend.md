# EPIC-01 공고 목록 화면 (Frontend)

## 목표

공고 목록 화면을 React로 구현한다. 공고 카드 UI, 검색, 필터, 정렬, 로딩/빈 상태/에러 상태를 포함한다.

---

## 파트

Frontend

---

## 참조 Rule

- `docs/rules/frontend/frontend-rule.md` ← 작업 전 생성 필요

---

## Done Condition

- [ ] React 앱이 브라우저에서 정상 실행된다
- [ ] 공고 목록이 카드 형태로 렌더링된다
- [ ] 카드에 적합도 점수/상태(색상 포함), 공고명, 기관명, 예산, 지역, 마감일(D-Day)이 표시된다
- [ ] 키워드 검색이 동작한다
- [ ] 필터(지역, 적합도 등급, 예산 범위)가 동작한다
- [ ] 정렬(점수순, 마감일순, 최신순)이 동작한다
- [ ] 로딩 / 빈 상태 / 에러 상태 UI가 표시된다
- [ ] 페이지네이션이 동작한다

---

## Out of Scope

- 로그인 / 회원가입 화면 → 별도 Task
- 공고 상세 화면 → 별도 Task
- 즐겨찾기 기능 → MVP 선택 기능 (구현 시 이 Task 범위에서 처리)
- 회사 프로필 화면 → Epic-2

## 작업 항목

- [ ] `frontend/` 하위에 React + Vite 프로젝트 초기화
- [ ] 의존성 추가
  - `@tanstack/react-query` (서버 상태 관리)
  - `react-router-dom` (라우팅)
  - `axios` (HTTP 클라이언트)
- [ ] axios 인스턴스 설정 (baseURL, CSRF 헤더 자동 추가, credentials: include)
- [ ] 공고 목록 API 훅 구현 (`useBidList`)
- [ ] 공고 목록 페이지 컴포넌트 구현 (`BidListPage`)
- [ ] 공고 카드 컴포넌트 구현 (`BidCard`)
  - 적합도 점수 색상: 80점↑ 초록 / 60~79점 주황 / 60점↓ 회색
- [ ] 검색 / 필터 / 정렬 컴포넌트 구현
- [ ] 로딩 상태 UI (스켈레톤)
- [ ] 빈 상태 UI (검색 결과 없음)
- [ ] 에러 상태 UI (재시도 버튼 포함)
- [ ] 페이지네이션 컴포넌트 구현
